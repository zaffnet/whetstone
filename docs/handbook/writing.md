# Writing

The catalog of AI writing tells lives in the `writing-whip` skill
(`skills/writing-whip/SKILL.md`), which reaches an agent at the moment of writing and
ships to machines that do not have this repo. Read it before writing prose.

House style on top of it:

- Plain sentences that state facts and decisions.
- Use a list when the material is a list.
- If the code, the doc, or the user already named something, use that exact word. Do not
  paraphrase a technical term, and do not coin a near-synonym of one.
- Sentence case in headings.
- Straight quotes, no em dashes, no arrow glyphs.

For prose written as part of a change (comments, docstrings, READMEs, design docs, PR
bodies), `skills/prose-honesty/SKILL.md` is the bar: does a reader who arrives next year,
having never seen the change, need this sentence?
